# fraud-guard-engine
When millions of people swipe credit cards, banks have under 100 milliseconds to decide: "Is this transaction real, or did a scammer steal this card?" If they take too long, the payment fails; if they guess wrong, they lose millions to fraud.
An automated security officer sitting between a store cashier and the bank. The second a card is swiped, the system checks the buyer's habits (e.g., location, time, spending amount) using Machine Learning and gives a "Risk Score." If the score is high, it blocks the payment or flags it for review.
